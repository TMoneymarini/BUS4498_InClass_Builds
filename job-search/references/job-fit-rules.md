# Job Fit Rules

Apply these rules in order. A posting that fails any "Drop" rule is removed and counted under the matching "Filtered out" reason.

## 1. Freshness
- Drop postings older than 30 days, based on the posted date on the original listing.
- Drop postings whose application deadline has passed.
- If no posted date is shown, keep the posting and note "Posted date not listed."
- Filtered-out reason: **expired**

## 2. Experience level
- Drop roles that ask for 2 or more years of professional experience, unless the posting is explicitly labeled internship, co-op, new grad, or entry-level.
- Drop titles containing Senior, Sr., Lead, Staff, Principal, Manager, or Director, unless the posting says it is an internship or entry-level role.
- Filtered-out reason: **too senior**

## 3. Degree timing
- Keep roles that accept candidates "currently enrolled" or "graduating by [date]" when the user's graduation date is on or before that date.
- Drop roles that require a completed degree before the start date when the user will not have finished by then.
- Drop roles that require a degree level the user is not pursuing (for example, a master's or PhD).
- Filtered-out reason: **missing requirement**

## 4. Clearance and certifications
- Drop roles that require an **active** security clearance the user does not have.
- Do not drop roles that say "clearance-eligible" or "must be able to obtain a clearance." Keep them, mark them "Clearance-eligible — confirm eligibility," and ask the user. Do not guess citizenship or work authorization.
- Drop roles that require a certification the user does not hold (for example, Security+, CISSP, or CCNA) when the posting says it is required. Roles that list a cert as "preferred" or "a plus" stay.
- Filtered-out reason: **missing requirement**

## 5. Location
- Drop roles outside the user's preferred locations unless the posting is fully remote and the user accepts remote work.
- Hybrid roles count as in-location only if the office is in a preferred location.
- Drop remote roles restricted to states or countries the user is not in.
- Filtered-out reason: **wrong location**

## 6. Duplicates
- The same title at the same company counts as one posting, even when it is listed on several boards or in several cities.
- Keep the link from the company's own careers page. If there isn't one, keep the most recently posted listing.
- Filtered-out reason: **duplicate**

## 7. Red flags
Drop postings that show any of the following:
- No company name, or a company that can't be verified.
- Pay-to-apply, training fees, or equipment purchases required.
- Requests for SSN, bank details, or ID documents before an interview.
- Commission-only or "unlimited earning potential" with no base pay.
- Contact only through personal email or messaging apps.
- Filtered-out reason: **missing requirement** (note "red flag" in the count line)

## Fit scoring
Count the requirements listed under "Required," "Minimum qualifications," or an equivalent section. Count "Preferred" items only if the posting lists no required section.

| Score | Rule |
|---|---|
| **High** | The user meets 80% or more of the listed requirements |
| **Medium** | The user meets 50–79% of the listed requirements |
| **Low** | The user meets under 50% of the listed requirements |

- A requirement counts as met only if the user's resume or skills summary shows it. Do not assume skills that aren't stated.
- Ties within a score break in this order: nearest deadline first, then highest listed pay, then most recent posting.
